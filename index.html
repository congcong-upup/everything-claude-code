这是什么？

Everything Claude Code 是一个开源的 Claude Code 插件仓库，将 Agents（代理）、Skills（技能）、Hooks（钩子）、Commands（命令）、Rules（规则）、MCP 配置 打包成一套即插即用的工程化工具箱。作者 @affaanmustafa 在 Anthropic 黑客马拉松中获胜，并在实际生产项目中迭代了 10 个月以上。

六大核心模块

A Agents 代理

11 个专业子代理，处理委托任务：实现规划、架构设计、TDD 引导、代码审查、安全审查、构建错误修复、E2E 测试、重构清理、文档同步，以及 Go 语言专用审查和构建修复。

S Skills 技能

43 个工作流 / 领域知识定义，涵盖编码规范、后端模式、前端模式、TDD 工作流、安全审查、持续学习、迭代检索、验证循环、Go/C++ 测试模式等。

C Commands 命令

18 个斜杠命令快捷入口：/tdd /plan /e2e /code-review /build-fix /learn /verify /go-review /skill-create /evolve 等。

H Hooks 钩子

基于触发器的自动化：会话开始/结束时的内存持久化、压缩前状态保存、战略性上下文压缩建议、会话模式提取。支持 PreToolUse / PostToolUse / Stop 事件。

R Rules 规则

6 个始终生效的规则模块：安全检查（无硬编码秘密）、编码风格（不可变性、文件组织）、测试（TDD、80% 覆盖率）、Git 工作流、代理委托策略、性能优化。

M MCP 配置

预配置的 MCP 服务器连接：GitHub、Supabase、Vercel、Railway 等，替换占位符即可使用。注意：不要同时启用超过 10 个 MCP。

关键概念速查

概念定义示例
Agent 以有限范围处理委托任务的子代理，拥有指定工具和模型 code-reviewer 代理：只用 Read/Grep/Glob/Bash 做代码审查
Skill 工作流定义 + 领域知识，由命令或代理调用 TDD 工作流：RED → GREEN → IMPROVE 循环
Command 斜杠命令入口，映射到代理或技能的快捷方式 /plan "添加用户认证"
Hook 在工具事件（Pre/Post/Stop）时自动触发的脚本 Edit 事件后自动检测 console.log 残留
Rule 始终生效的指南约束，保持模块化 security.md：禁止硬编码 API Key
Instinct 持续学习 v2 的核心，从会话中自动提取模式并带置信度评分 自动学习你的代码风格偏好并复用

适用人群 & 注意事项

适合谁？

使用 Claude Code 进行日常开发的工程师，希望通过代理、技能、规则等模块化配置来系统性提升 AI 编程的效率和质量。

不适合谁？

不使用 Claude Code 的用户；期望"银弹"解决方案的用户 —— 作者强调这些配置需要根据你自己的技术栈进行定制。

重要注意事项

  • 上下文窗口：不要一次启用所有 MCP。配置 20-30 个 MCP 但每个项目保持启用少于 10 个，活动工具少于 80 个，否则 200k 上下文可能缩小到 70k。
  • 需要定制：这些配置适用于作者的工作流。你应该从适合你的开始，为你的技术栈修改，删除不用的，添加自己的模式。
  • Rules 需手动安装：Claude Code 插件系统不支持自动分发 rules，需要手动复制到 ~/.claude/rules/。

总结评价

核心价值

  • 工程化：把 AI 编程助手的使用从"随手对话"提升到"系统工程"层面，通过代理分工、技能复用、规则约束、钩子自动化来保证质量和一致性。
  • 模块化：六大模块独立解耦，按需取用，不必全部采纳。
  • 持续学习：v2 的 Instinct 系统让 Claude Code 能够跨会话积累你的编码偏好，越用越懂你。
  • 实战验证：经过 10+ 个月、多个生产项目、Anthropic 黑客马拉松验证，不是纸上谈兵。

一句话总结

Everything Claude Code = Claude Code 的"操作系统级"配置框架，用代理编排 + 技能复用 + 规则约束 + 钩子自动化，把 AI 编程从单次对话升级为系统化工作流。
